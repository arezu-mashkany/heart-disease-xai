# 🫀 سامانه هوشمند و توضیح‌پذیر تشخیص بیماری قلبی (Heart Disease XAI Dashboard)

پروژه کارشناسی هوش مصنوعی — داشبورد تعاملی پیش‌بینی ریسک بیماری‌های قلبی عروقی همراه با توضیح‌پذیری مدل (XAI) با استفاده از کتابخانه SHAP و فریم‌ورک Streamlit.

---

## 📌 درباره پروژه
این سامانه با هدف کمک به پزشک و کادر درمان طراحی شده است تا علاوه بر پیش‌بینی احتمال ابتلای بیمار به بیماری‌های قلبی در یک بازه ۱۰ ساله (بر اساس مطالعه معتبر **Framingham**)، **دلیل** تصمیم‌گیری مدل هوش مصنوعی را نیز به صورت شفاف و تفکیکی برای هر بیمار نمایش دهد. 

استفاده از هوش مصنوعی توضیح‌پذیر (XAI) کمک می‌کند تا پزشکان بتوانند به نتایج مدل اعتماد کرده و بدانند کدام پارامترهای بالینی (مانند فشار خون، کلسترول، قند یا سیگار) بیشترین تأثیر را در امتیاز ریسک بیمار داشته‌اند.

---

## 🚀 ویژگی‌های کلیدی سامانه
- **طراحی کاملاً بومی و راست‌چین (RTL):** بهینه‌سازی‌شده برای کاربران فارسی‌زبان با فونت استاندارد وزیرمتن.
- **ورودی‌های بالینی انعطاف‌پذیر:** امکان تایپ مستقیم مقادیر یا استفاده از دکمه‌های کنترل عدد برای پارامترهای بیمار.
- **تحلیل فردی با SHAP:** ارائه نمودارهای آبشاری (Waterfall) و تحلیلی برای هر بیمار به‌صورت اختصاصی.
- **نمایش سطح ریسک:** دسته‌بندی هوشمند ریسک به سه سطح (پایین، متوسط و بالا) همراه با نوار پیشرفت و راهنمایی بالینی.
- **مبتنی بر داده‌های واقعی:** استفاده از داده‌های استاندارد قلب و عروق Framingham Heart Study.

---

## 🛠️ تکنولوژی‌ها و کتابخانه‌ها
- **زبان برنامه‌نویسی:** Python 3.10+
- **رابط کاربری (UI):** Streamlit
- **یادگیری ماشین:** Scikit-Learn (Random Forest Classifier)
- **توضیح‌پذیری هوش مصنوعی (XAI):** SHAP (SHapley Additive exPlanations)
- **مصورسازی داده‌ها:** Matplotlib & Seaborn
- **نسخه‌محوری و استقرار:** GitHub & Streamlit Community Cloud
